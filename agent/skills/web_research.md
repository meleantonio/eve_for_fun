description: Systematic web scanning for new AI techniques relevant to economic research.
---

When scanning the web:

1. Query multiple angles, but do **not** force a hit every week. Prefer primary artifacts
   (paper + code + real data) over category-query filler.
2. Prefer the last 7–14 days; include arXiv, GitHub, major labs, and econ-tech blogs.
3. Use `webSearch` (built-in) for each query; cross-check claims against primary sources.
4. Deduplicate by **technique family** (not only URL/title) before recording discoveries.
   Goal-loop variants, PDF-extraction clones, and slug near-matches are one family.
5. Skip marketing fluff without reproducible artifacts (runnable code, paper, or docs)
   **and** a named real dataset/object.
6. If nothing clears the bar, record nothing publishable. Zero tutorials beats filler.

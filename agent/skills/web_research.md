description: Systematic web scanning for new AI techniques relevant to economic research.
---

When scanning the web:

1. Query multiple angles: "LLM causal inference", "AI economic forecasting",
   "structured extraction PDF economics", "agentic data pipeline research".
2. Prefer the last 7–14 days; include arXiv, GitHub trending, major labs, and econ-tech blogs.
3. Use `webSearch` (built-in) for each query; cross-check claims against primary sources.
4. Deduplicate by URL and title before recording discoveries.
5. Skip marketing fluff without reproducible artifacts (code, paper, or docs).
